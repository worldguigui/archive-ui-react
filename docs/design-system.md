# ARCHIVE UI 设计语言 · V0.1

> A World of Vintage Mystery
>
> 本文档是 archive-ui-react 的正式设计规范（Design Language Spec）。视觉基线已于 2026-11-25 冻结（决议见 `docs/decisions/`）：三材质、混合模式、氛围层与装饰体系为正式能力。渲染架构见 `docs/rendering-system.md`，材质参数见 `docs/materials/`。文档末尾列出尚未实现的能力。

## 一、定位与视觉基因

archive-ui-react 的设计语言不是"黑金配色皮肤"，而是一套完整的视觉艺术指导，工作定义为：

**Retro-Futurist Editorial · 复古未来主义编辑设计**

将 20 世纪复古印刷品、欧洲古典编辑设计、装饰艺术（Art Deco）、电影摄影与现代数字交互融合的视觉语言。关键词：复古、戏剧性、神秘、档案感、电影感、装饰艺术。

三条核心判断：

1. **不是单一历史时期的怀旧，而是时代错位感。** 维多利亚装饰、20 世纪早期印刷品、Art Deco 几何、现代电影海报叙事共存，经过艺术加工而非历史复原。
2. **不是平整干净的数字界面，而是有物理媒介暗示的表面。** 纸张纤维、印刷颗粒、油墨浓淡、轻微褪色、暗角——界面应像来自实体档案、旧书、展览手册或历史文献。
3. **大量留白，但不追求极简。** 内容按编辑设计（Editorial Design）组织：大标题是视觉锚点，图片是叙事主体，正文像杂志文章，装饰符号承担导航与索引。

### 九个设计维度总览

| # | 维度 | 核心关键词 |
|---|------|-----------|
| 01 | 色彩 | 暗色基底、低饱和、冷暖对照 |
| 02 | 材质 | 纸张、油墨、金属、胶片 |
| 03 | 光影 | 暗角、环境光、辉光、雾 |
| 04 | 造型与装饰母题 | 几何、古典、神秘学、档案 |
| 05 | 字体 | 衬线、宋体、无衬线、数字字体 |
| 06 | 版式与构图 | 编辑式、沉浸式、仪器式 |
| 07 | 疏密节奏 | 高/中/低密度分区 |
| 08 | 图像处理 | 电影感、裁切、颗粒、色偏 |
| 09 | 仪式性交互 | 符号显现、扩散、消散 |

其中 01–06 已落地为 Token，07–08 为使用规范（无需代码），09 已完成设计定义、实现列入计划。

### 视觉分层总纲

视觉体系自底向上分五层（架构细则见 `docs/rendering-system.md` §二）：

| 层 | 职责 |
|---|---|
| L1 Base | 底色、色彩渐变、基础氛围（氛围子层不受强度缩放） |
| L2 Material Texture | 材料自身表面特征 |
| L3 Lighting | 环境光、暗角、高光、阴影、光晕 |
| L4 Structure & Decoration | 边框、角饰、印章、纹章、文字及前景图形 |
| L5 Interaction | 交互反馈与动态特效，按需出现 |

核心原则：**视觉构成与材质表现解耦——可组合，不可互相替代。** 装饰元素不继承面板材质纹理；判断一个视觉问题属于哪一层，是所有后续设计工作的第一步。

## 二、Token 三层架构

```
Primitive（原始值）→ Semantic（用途映射）→ Component（组件引用语义层）
```

- **Primitive**：`src/styles/tokens/primitives.css` 等 Token 文件。只表达"有哪些值"，组件**禁止直接引用**。
- **Semantic**：`src/styles/themes/default.css`。按用途命名（`--au-color-bg-canvas` 等），暗色档案为默认主题，`[data-theme='light']` 提供亮色羊皮纸变体。
- **Component**：组件样式只引用 Semantic 层变量，不硬编码视觉数值。

TS 侧 Token（`src/tokens/`）与 CSS 数值一一对应，仅供脚本场景（Playground 主题编辑器、未来的主题工具）使用。

命名规范：CSS 变量统一 `--au-{类别}-{名称}`；class 统一 `au-` 前缀 BEM。

## 三、维度 01 · 色彩体系

**不能简单定义为黑金配色。** 共享的底层色彩逻辑：

- 整体饱和度受控；
- 暗部不是纯黑，而是带色相的深色（墨色系）；
- 高光不是纯白，而是偏暖的灰白（象牙/羊皮纸）；
- 强调色集中使用，不同时抢夺注意力；
- 冷暖关系服务于场景（环境光冷暖由光影 Token 承担，而非大面积色块）。

## 四、维度 02 · 材质语言

复古感的核心不是"颜色旧"，而是**界面具有实体媒介的触感**。纹理不应是背景图片，而是界面的第二层视觉信息。

| 材质 | 表现 | 用途 | 状态 |
|---|---|---|---|
| 哑光 Plain | 近中性微颗粒、无方向条纹 | 功能面板、密集信息 | **已实现**（`plain`） |
| 纸张 Paper | 纤维、斑驳、边缘磨损 | 档案卡片、信件、标签 | **已实现**（`paper`） |
| 油墨 Ink | 网点、颗粒、套印偏移 | 标题叠层、装饰印章 | 计划 |
| 金属 Metal | 暗铜、旧金、蚀刻、磨损 | 边框、徽章、按钮轮廓、编号 | Token 已备，组件计划 |
| 木质 Wood | 深木纹、低反射 | 背景、书架式容器 | 计划 |
| 胶片 Film | 颗粒、灰雾、暗角、色散 | 图片展示、沉浸式背景 | **已实现**（`film`，真实乳剂亮度图） |
| 烟熏玻璃 Smoked Glass | 半透明、暗色遮罩、局部反光 | 悬浮面板、弹窗 | 计划 |

### 强度分级（硬性规范）

| 等级 | 效果 | 使用位置 |
|---|---|---|
| 0 | 完全平整 | 表单、数据、密集信息 |
| 1 | 极轻微颗粒 | 普通容器 |
| 2 | 纸张/印刷纹理 | 档案、展示卡片（当前 `paper` 材质所处等级） |
| 3 | 明显磨损、暗角、胶片效果 | 海报、沉浸式场景 |

**禁止整页覆盖强噪点**——那会沦为廉价的做旧主题。纹理应在暗部可感知、在正文与交互区域克制。强度全部由 Token 控制：入口 `--au-texture-grain-opacity` / `--au-texture-dust-opacity`，各材质档位见 `src/styles/tokens/materials.css`。

### 纹理叠加方式（硬性规范）

纹理层与底色有两种正式叠加方式，经混合模式入口 `--au-material-grain-blend` 选择：

| 方式 | 混合模式 | 机制 | 适用 |
|---|---|---|---|
| 描纸式叠加 | `normal`（默认） | 半透明纹理如描图纸覆于底色之上 | Alpha 调制型资产（paper、plain） |
| 正片叠底 | `multiply` | 颜色逐通道相乘：暗部压深、亮部透出底色 | 不透明亮度图资产（film 乳剂） |

不透明资产禁用 normal（会以贴图方式盖死底色）；半透明资产禁用 multiply（会过度压暗）。

### 氛围层（L1 子层）

材质的身份氛围由 `--au-material-atmosphere-image` 承载（灯光渐变类，画在底色之上、纹理之下），**不参与任何强度缩放**——氛围是基底的一部分，不是可调效果。plain 的纵深渐变与 paper 的灯光进深均由此承载。

## 五、维度 03 · 光影语言

区分两种渐变：**色彩渐变**（色相过渡，本规范禁止用于按钮）与**光影渐变**（光源衰减，营造空间感，本规范的精髓）。

| 光影类型 | 视觉表现 | 用途 | Token |
|---|---|---|---|
| 暗角 Vignette | 四周压暗、中心突出 | 首页、展示背景、纸张进深 | `--au-gradient-vignette` |
| 局部辉光 Glow | 橙金色光晕 | 选中态、强调（克制） | `--au-glow-gold` / `--au-glow-oxide` |
| 环境雾 Haze | 低对比雾状层 | 背景与图片 | `--au-gradient-atmosphere-warm` / `-cool` |
| 线性光带 Light Sweep | 细长方向性光线 | 装饰、过场 | 计划 |
| 阴影衰减 Shadow Falloff | 边缘融入背景 | 卡片、浮层 | `--au-shadow-soft` / `--au-shadow-deep` |
| 旧金属 | 蚀刻金属明暗 | 徽章、编号、金属边框 | `--au-gradient-antique-gold` |

**使用边界：** 渐变承担环境光、空间深度与材质表现；不得出现现代 SaaS 式彩色渐变按钮。

## 六、维度 04 · 造型与装饰母题

六组母题，**不可平均分配**，按主次使用：

- **一级母题（日常使用）**：几何装饰（同心圆、放射线、角花、几何边框）、档案标记（印章、编号、日期、索引符号）、编辑排版（分栏、细分隔线、页码、栏目标签）。
- **二级母题（点缀）**：神秘学符号（星盘、轨道、天体）、古典装饰（卷草纹、徽章、雕刻线条）。
- **三级母题（场景化）**：自然装饰（植物、昆虫、羽毛、有机曲线）。

目标：保留复古神秘气质，但不让每个组件都像神秘学仪式道具。

### 线条节奏（硬性规范）

线条分四类，必须呈现层级、节奏与疏密变化，禁止同粗细/同色/同透明度：

1. **结构线**：分区、边界（`--au-color-border-subtle` + hairline 宽度，稳定克制）
2. **装饰线**：标题、章节、分隔（金属色/强调色，允许渐变）
3. **定位线**：坐标、索引、标记（细 + 半透明）
4. **轨迹线**：轨道、曲线、神秘学图形（最轻，常配合动效）

装饰不透明度分级：`--au-ornament-opacity-subtle/normal/strong`（0.25/0.6/0.9）；尺寸分级 `--au-ornament-size-sm/md/lg`（12/24/48px）。

### 装饰实现规则（硬性规范）

1. **装饰元素不继承面板材质纹理**——装饰是构成，不是材质表面的一部分。
2. 装饰以真实 DOM 子元素实现（装饰 span + `aria-hidden`），禁止占用组件伪元素（伪元素属于纹理/光影槽）。
3. 图形资产经 mask 消费、语义 Token 着色，一份形状服务明暗两主题；保留笔迹原色的素材（签名纹章）可直接图片消费。
4. **纹章体系**：印章、徽记、签名为纹章的三类样式分支（签名不单列），落款位约定为右下，允许小角度旋转。

### 已定装饰词汇（基线冻结版）

- 边框变体：局部断开边界 / 不完整矩形轮廓 / 细线+边缘符号 / 文字融入边框 / 纹章落款（草案陈列于 RenderLab 第八区，装饰 API 立项时逐款转正）；
- 分隔线：蚀刻渐变线（正式）/ 细双线 / 点线 / 长短错位线（草案）；
- 角饰：现状款（正式）+ 双线倒角 / 圆弧刻度 / 制图刻度（草案）；
- 纹样：阶梯折线 / 节点竖线 / 谐振徽版（草案）。

## 七、维度 05 · 字体方案

四类字体角色（当前为系统字体栈；自带字体文件为后续计划，引入时放入 `src/assets/fonts/`）：

| 角色 | Token | 方向 | 使用场景 |
|---|---|---|---|
| Display | `--au-font-family-display` | 高对比衬线 | 大标题、章节名称 |
| Editorial | `--au-font-family-editorial` | 古典衬线（中文宋体） | 正文、故事性内容 |
| UI | `--au-font-family-ui` | 现代无衬线 | 表单、按钮、操作、密集数据 |
| Numeric | `--au-font-family-numeric` | 等宽/窄体 | 编号、时间、统计 |

字号：display 3rem / heading 1.75rem / title 1.25rem / body 0.9375rem / caption 0.75rem。字距：display 0.12em / heading 0.08em / label 0.16em。行高：editorial 1.85 / normal 1.6 / tight 1.35。

**两条硬性边界：**

1. **不要让所有文字都变成衬线体**——信息密集界面会失去可读性。衬线用于展示性文字，无衬线留给高效阅读与操作。
2. 中英混排基线：中文宋体 + 英文高对比衬线；UI 信息用无衬线；数字必须等宽对齐。

## 八、维度 06 · 版式与构图

三种构图模式**共存**，按内容类型选择：

| 模式 | 构图特点 | 适用 |
|---|---|---|
| Immersive 沉浸式 | 图片为主体，界面元素作为覆盖层 | 首页、封面、角色展示 |
| Editorial 编辑式 | 大标题 + 图片 + 正文的明确视觉重心 | 档案、世界观、文章 |
| Instrumental 仪器式 | 紧凑、精确、细线分区，装饰服务信息结构 | 数据面板、管理页、榜单 |

如果所有页面都像海报——漂亮但难用；都像后台——好用但没有表现力。

## 九、维度 07 · 疏密节奏（使用规范）

- **高密度区**：信息、表格、列表 → 装饰几乎为零（材质等级 0–1），靠明暗与发丝线分区。
- **中密度区**：卡片、导航、操作区 → 允许等级 2 材质与一级母题。
- **低密度区**：标题、封面、背景 → 允许等级 3 材质、二级母题与光影氛围。

留白是版面的一部分，不要把装饰塞满每个角落。

## 十、维度 08 · 图像处理（使用规范）

代码层暂不实现，使用时遵循：

- 图片必须有暗角与色调统一处理（冷色场景用 fog-blue 系，暖色场景用 oxide 系）；
- 允许人物局部裁切、主体偏移——电影剧照式的不完整性比完整展示更有表现力；
- 颗粒与色散强度对齐材质等级表；
- 图片与文字叠加时，文字侧必须有遮罩渐变保证可读性（`--au-color-overlay`）。

## 十一、维度 09 · 仪式性交互（Ritual Interaction）

将常规数字交互转化为微型仪式。**当前状态：设计定义完成，实现为计划任务**（规划模块 `src/interaction-effects/`：InteractionProvider + 全局渲染层 + presets）。

### 视觉元素五类

| 元素 | 表现 | 用途 |
|---|---|---|
| Glyph | 小型神秘符号、星体、几何图案 | 点击位置装饰 |
| Ring | 同心圆、刻度环、环形轨道 | 点击范围反馈 |
| Typography | 环绕小字、罗马数字 | 仪式感 |
| Particles | 微小光点、星尘 | 扩散与消散 |
| Traces | 轨迹线、弧线、残影 | 动态层次 |

### 动画生命周期（建议 500–800ms）

1. **Trigger** 触发：交互位置出现微小光点；
2. **Reveal** 显现：环绕文字、刻度、几何图形迅速显现；
3. **Expand** 扩散：环形扩大、符号旋转、光点外扩；
4. **Dissolve** 消散：透明度降低、线条消失，不留视觉负担。

### 预设风格

`celestial`（同心圆星体刻度，缓慢旋转）/ `engraving`（雕刻线条分段显现）/ `typographic`（环绕罗马数字字符轨道）/ `ethereal`（光点粒子辉光）。

### 事件矩阵

| 事件 | 反馈 |
|---|---|
| Click | 环形符号显现、扩散 |
| Hover | 微弱刻度显现、边框辉光 |
| Select | 印章或徽记浮现 |
| Success | 金色环形收束 |
| Error | 锈红断裂线、短暂震荡 |
| Loading | 环形刻度持续旋转 |
| Navigation | 罗马数字、章节装饰过渡 |

### 实现约束（硬性）

- 独立全局渲染层，禁止每个按钮各自挂载动画 DOM；
- `pointerdown` 获取坐标；装饰层 `pointer-events: none`；
- 限制同时存在的特效数量；
- 尊重 `prefers-reduced-motion`，提供关闭能力；
- **克制原则：不要让每次鼠标移动都产生特效**。点击时短暂出现、然后消失，比持续跟随鼠标的粒子效果高级得多。

### 交互状态基线

| 状态 | 反馈 |
|---|---|
| Default | 暗色底、细边框 |
| Hover | 边框提亮（金属色）、局部暖光（`--au-glow-gold`） |
| Active | 背景加深、装饰线显现 |
| Selected | 锈橙标记、编号或徽章 |
| Disabled | 降低对比度、去除辉光 |
| Loading | 细线进度、环形刻度 |

动效基调：缓慢、克制、有仪式感（`--au-transition-base: 180ms ease`），但操作反馈必须及时。

## 十二、视觉验收标准

每个实验室页面（Playground）用于校准，验收看综合效果：

1. **色彩**：同一视图只有一个强调主角；暗部有色相；高光偏暖；三级背景纵深可辨。
2. **材质**：等级 2 的卡片在暗部能感知颗粒，正文区域无干扰；整页无强噪点。
3. **光影**：暗角与氛围光可感知但不抢夺内容；无彩色渐变按钮。
4. **装饰**：一个视图内装饰母题不超过两级；线条有粗细/颜色/透明度差异。
5. **字体**：同一页面衬线不超过两种角色；数据区为无衬线/等宽；数字对齐。
6. **交互**：反馈及时（≤200ms 级）、特效短暂、可关闭。

## 附：借鉴边界

借鉴的是**设计方法与视觉语法**，部分组件可以直接复制游戏资产，但更多要采用借鉴。风格应能表现雨夜伦敦、古典植物园、档案室、神秘学研究所等不同氛围，同时维持统一的视觉基因。
