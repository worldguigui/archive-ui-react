# 决策 003 · film 材质采用真实乳剂位图与 multiply 混合

- 日期：2026-11-25
- 状态：已接受

## 背景

film 纹理此前为手绘整幅 SVG（齿孔/划痕/尘点/暗角一体，1600×1200）。两个问题：

1. **自带烘焙暗角**（中间亮四周暗），与 L3 光影槽的 lens 暗角双重承载，
   作为材质资产超规格——宏观光影应唯一归 L3；
2. 程序化 feTurbulence 无法再现真实摄影质感（划痕的惯性、分叉、深浅不一），
   且其颗粒密度随绘制尺寸漂移、量化校准受限（Chromium 对带滤镜 SVG 的
   drawImage 返回空图）。

维护者提供真实底片照片素材后，在混合模式矩阵中验证了 multiply 观感并获得认可。

## 决策

1. film 纹理采用**真实底片照片衍生的乳剂亮度图**：
   - `film-emulsion.webp`（暗版，1285×565，28.7KB）：黑场 + 亮划痕；
   - `film-emulsion-light.webp`（亮版反转图，25.2KB）：浅场 + 深划痕，亮主题专用；
   - 两版均为灰度、无烘焙暗角、裁除齿孔（齿孔为 L4 叙事图形）。
2. **multiply 混合**：黑场 × 底色 = 压暗，白划痕 × 底色 = 透出底色，
   形成"底色场 + 对比划痕"；不透明亮度图用 normal 会以贴图方式盖死底色。
   档位为 1（全强度），强度语义为黑场压暗程度。
3. 显示形态 cover + center + no-repeat（裁切边缘划痕断开，不可无缝平铺）。
4. **手绘 film-grain.svg 退役删除**；带齿孔整幅 `film-strip.webp` 留存于
   Playground trial 目录，作为 L4 展示位路线的试验资产。

## 影响

- 正式管线引入纹理混合模式入口 `--au-material-grain-blend`（默认 normal，
  不影响其他材质）与位图资产构建支持（webp/jpg/png loader）；
- 构建产物 CSS 打包需处理位图路径改写（`pnpm build:css`）。
