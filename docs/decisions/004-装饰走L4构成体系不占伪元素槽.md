# 决策 004 · 装饰走 L4 构成体系，不占材质伪元素槽

- 日期：2026-11-25
- 状态：已接受

## 背景

组件的 `::before` / `::after` 已被纹理槽（L2）与光影槽（L3）占用。
装饰元素（边框变体、角饰、纹章、分隔线、纹样）若无固定载体约定，
会与材质槽位争用伪元素或混入材质类职责。

## 决策

1. **装饰一律以真实 DOM 子元素实现**（装饰 span + `aria-hidden="true"`），
   与 Panel corners 的既有模式一致；禁止占用组件伪元素。
2. 图形资产经 **mask 消费**：形状在 SVG 资产中，颜色取语义 Token
   （`background-color` + `mask`），随主题自动切换——一份形状服务明暗两主题。
   保留笔迹原色的素材类（如签名纹章）可直接以图片消费。
3. **装饰元素不继承面板材质纹理**：装饰是构成，不是材质表面的一部分；
   装饰自身的小表面质感（如金属角饰）走装饰自己的着色，永不叠加面板纹理。
4. 装饰与材质是正交组合：`material` × `decoration` 各自独立选择。

## 影响

- 组件 DOM 形态约定：装饰 span 结构即正式 API 的实现形态；
- 纹理/光影/装饰三个维度可在同一组件上无冲突并存；
- RenderLab 第八区（构成变体库）的 span 结构为转正形态样本。
