# 决策 005 · 视觉基线冻结决议（C1–C6）

- 日期：2026-11-25
- 状态：已接受（基线冻结）

## 决议明细

| # | 议题 | 决议 |
| --- | --- | --- |
| C1 | Signature 素材（角色签名/徽记 webp） | 定性为致敬性小规模复用，可用；`design-system.md` 借鉴边界条款同步修订。签名作为**纹章样式之一**并入纹章体系，不单列类别 |
| C2 | film 纹理路线 | 采用真实乳剂 webp（见决策 003）；手绘 SVG 退役 |
| C3 | paper 暗主题明度 | 深棕 `#332a23`（正式）；样品区保留中调羊皮纸 `#6e5a3c` 作对照陈列 |
| C4 | 三材质样品验收 | 通过并转正：plain = 哑光微颗粒 + 纵深氛围层；paper = 深棕底 + 灯光氛围层；film = 乳剂亮度图。氛围层（L1 子层）随本轮成为正式能力 |
| C5 | 构成变体淘汰 | 淘汰：中点菱形分隔线、印章落款边框变体（环形印章资产保留于纹章样式对照）；其余变体留待装饰 API 立项时转正 |
| C6 | 混合模式入口 | 落地 `--au-material-grain-blend`；normal（描纸式叠加）与 multiply（正片叠底）两种叠加方式并列保留为正式能力 |

## 同批清理记录

- 删除无消费者 Token：`--au-texture-paper-opacity`、`--au-material-border-worn`、
  `--au-material-ink`、`--au-material-metal-hi/lo`；
- 删除组件基色 fallback，默认值单轨化；
- 删除探索期产物：4 个 `.backup` SVG、试验用 jpg、v1 基线对照资产与预览区；
- `draft-plain-matte.svg` 随 plain 转正更名为 `plain-matte.svg`；
- 图源登记变量统一为 `--au-texture-{material}-grain-image` 家族。

## 冻结边界

- 正式：Token 三层架构、五层渲染模型、三材质、混合模式入口、显示形态入口、
  主题成对机制、装饰 span 模式；
- 实验保留：RenderLab 全部区块、trial 资产、构成变体库（待装饰 API 立项）、
  纹章/纹样草案；
- 后续修改基线（材质档位、基色、槽位结构、五层职责）须先出新决策记录。
