# 决策 001 · 五层渲染模型与构成/材质解耦

- 日期：2026-11-24
- 状态：已接受

## 背景

视觉风格开发长期集中在纹理参数调优上，试图以此逼近整体美术气质，反复迭代仍不达预期。
项目维护者定性了根因：**叠加图层是视觉构成，纹理底图是材质表现，是两个不同问题**；
一套 UI 的视觉风格来自形状、色彩、空间、材质、光线、字体与装饰的整体组织方式。

## 决策

视觉体系按五层组织（自底向上）：

| 层 | 职责 | 载体 |
| --- | --- | --- |
| L1 Base | 底色、色彩渐变、基础氛围 | 元素 `background-color` / `background-image`（氛围子层） |
| L2 Material Texture | 材料自身表面特征（纤维/颗粒/乳剂） | `::before` 纹理槽 |
| L3 Lighting | 环境光、暗角、高光、阴影、光晕 | `::after` 光影槽 + 阴影/辉光 Token |
| L4 Structure & Decoration | 边框、角饰、印章、文字及前景图形 | 组件 DOM（装饰 span），不一定同层 |
| L5 Interaction | Hover/Selected/点击反馈、动态特效 | 状态样式，按需出现 |

色彩与排版是贯穿性规范（Token 层），不设独立渲染层。
三槽位（Base/Texture/Lighting）只是**材质与光影的合成机制**，不是完整视觉架构。

**构成与材质解耦：可组合，不可互相替代。** 装饰元素不继承面板材质纹理；
胶片齿孔条类"叙事图形"归 L4（构成资产，按布局裁切），L2 只承载可平铺表面肌理。

## 影响

- `panel.css` 槽位结构按此模型实现；RenderLab 第七区（维度隔离归因）为配套验证工具；
- 工作顺序确立"构成先行"：构成稿在 plain 中性材质上验证，通过后再精修纹理；
- 视觉问题归因方法：逐层启停，定位问题维度。
