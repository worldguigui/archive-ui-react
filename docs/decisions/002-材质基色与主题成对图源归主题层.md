# 决策 002 · 材质基色与主题成对图源归主题层

- 日期：2026-11-24（基色），2026-11-25（主题成对图源）
- 状态：已接受

## 背景

材质基色（`--au-material-paper-base` / `--au-material-film-base`）曾定义在
`tokens/materials.css` 的 `:root`，属于主题无关的常量。透明纹理资产的观感
完全由底色承载，导致亮色主题下 paper 面板仍呈深棕底。

film 材质改用不透明亮度图后（决策 003），同一图源无法同时服务明暗两主题
（multiply 在亮底上会把面板压黑），图源也必须随主题切换。

## 决策

1. **随主题变化的材质身份要素一律归主题层**（`themes/default.css`，明暗各映射一份）：
   - 材质基色 `--au-material-paper-base` / `--au-material-film-base`；
   - 主题成对纹理图源 `--au-texture-film-grain-image`（暗版 / 亮版反转图）。
2. `tokens/` 层禁止持有随主题变化的值，只保留主题无关的档位与入口默认。
3. 亮色主题的暗角渐变同步在主题层重映射（黑基暗角在浅色纸面上突兀，
   改暖褐基低强度，保持"灯光下的纸张渐暗"语义）。

## 影响

- 主题层职责扩大：语义色 + 材质基色 + 主题成对图源 + 主题相关渐变；
- 新增材质时须同时提供明暗两套基色；不透明资产须提供明暗成对图源；
- 组件样式的基色 fallback 删除，默认值单轨化（材质类是唯一来源）。
