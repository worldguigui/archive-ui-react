# 渲染体系与美术资源架构

> 本文档定义 archive-ui-react 的渲染体系与美术资源体系。
> 关键架构决策的背景与取舍见 `docs/decisions/`；材质参数明细见 `docs/materials/`。

## 一、定位与边界

archive-ui-react 的目标不是一套 CSS 皮肤库，而是一套**具有完整美术资源体系和渲染能力的 UI 组件库**。

三条边界声明：

1. **视觉风格由组件库统一定义，美术资源由项目维护者提供。** 所有美术资源由本项目设计、绘制或程序生成（含致敬性复用），随组件库一起维护与分发。
2. **"自定义"指项目内部自制和替换美术资源**（对内的资产生产管线），不代表向组件调用者开放任意主题创作能力。调用方可使用的只有字符串预设与少量强度调整参数。
3. **基础使用保持简单，高级渲染细节由组件内部管理。** 例如 `<Panel material="paper" tier="editorial" />` 一行即得完整视觉；卡片内部叠加了多少图层、用了什么技术，调用方无感。

## 二、五层渲染模型

视觉体系自底向上分五层；色彩与排版是贯穿性规范（Token 层），不设独立渲染层。

| 层 | 职责 | 载体 |
| --- | --- | --- |
| L1 Base | 基础底色、色彩渐变、基础氛围 | 元素 `background-color` + `background-image`（氛围子层） |
| L2 Material Texture | 材料自身表面特征（纤维/颗粒/乳剂） | `::before` 纹理槽 |
| L3 Lighting | 环境光、暗角、高光、阴影、光晕 | `::after` 光影槽 + 阴影/辉光 Token |
| L4 Structure & Decoration | 边框、角饰、印章、文字及前景图形 | 组件 DOM（装饰 span），不一定同层 |
| L5 Interaction | Hover/Selected/点击反馈、动态特效 | 状态样式，按需出现 |

**构成与材质解耦：可组合，不可互相替代。** 装饰元素不继承面板材质纹理；
叙事图形（如胶片齿孔条）归 L4 构成资产，L2 只承载表面肌理。
暗角唯一承载方为 L3——纹理资产禁止内置烘焙暗角。

## 三、渲染槽位模型（Slot Schema）

三槽位是材质与光影的合成机制：

| 槽位 | 载体 | 消费的入口变量 | 强度缩放 |
| --- | --- | --- | --- |
| Base | 元素自身 `background` | `--au-material-base`、`--au-material-atmosphere-image`（氛围子层） | 不缩放（基底） |
| Texture | `::before` | `--au-material-grain-image` × 显示形态（`-size` / `-position` / `-repeat`） × 混合（`-blend`） × `--au-texture-grain-opacity` | `--au-texture-scale` |
| Lighting | `::after` | `--au-material-vignette-image` × `--au-material-vignette-opacity` | `--au-lighting-scale` |

层预算与扩展规则：

1. **槽内允许多图层**：一个槽位以 `background-image` 列表装配多层资产，配 `background-blend-mode` 列表控制层间混合。
2. **独立性边界 = 强度缩放的分组边界**：需要被独立调节的图层组必须分属不同槽位。
3. **三槽位不是硬性上限**：出现确实需要独立调节的新效果维度时，允许增加内部渲染层；现阶段不提前扩张。

不变式：材质类（`.au-material--*`）只写 custom properties（档位 × 响应系数 → 入口变量），禁止直接书写外观属性；组件样式表是唯一绘制方。使用混合模式的组件容器须建立隔离层叠上下文（`isolation: isolate`），混合不泄漏到页面背景。

## 四、CSS 与美术资产的职责分界

- **CSS 负责**：基础渐变、边框、阴影、状态变化、过渡与动画、图层混合等常规视觉表现。
- **美术资产负责**：CSS 难以达到目标气质的复杂表现——感光颗粒、纸浆纤维、氧化斑驳、真实划痕、装饰纹样等。

引入一张资产的判定标准：CSS 表达无法达到目标美术气质，或资产方式明显更优。能用且适合用 CSS 表达的，留在 CSS。

## 五、纹理资产规范

### 资产分类与显示形态

| 类别 | 定义 | 颜色承载 | 显示形态 |
| --- | --- | --- | --- |
| Alpha 调制型 | 只调制明度/质感（paper、plain） | 稀疏 alpha，允许低强度色温倾向，禁止承载身份底色 | 可平铺：固有尺寸 + `repeat` |
| 亮度图型 | 不透明灰度图，经混合模式与底色合成（film 乳剂） | 亮度信息；暗版/亮版反转图按主题成对 | 整幅构图：`cover` + `center` + `no-repeat` |
| 构图叙事型 | 结构叙事图形（齿孔、徽记） | 允许 | L4 构成资产，按布局摆放与裁切 |

规则：

- **可平铺资产渲染尺寸恒等于固有尺寸**（1 user-unit : 1 CSS px），禁止用 `background-size` 缩放平铺资产（feTurbulence 颗粒密度随绘制尺寸漂移）；
- 整幅资产 cover 裁切为受控语言，须居中锚定并声明裁切安全区；禁止用与纵横比不符的固定尺寸强制缩放；
- **主题成对**：不透明资产须提供明暗两版（暗版 + 亮版反转图），图源变量由主题层重映射；
- SVG 须为 XML 1.0 合法文件：**注释中禁止连续连字符**（`--`），否则浏览器静默解码失败、纹理渲染空白；
- 命名 `<主体>-<变体>.<ext>`，kebab-case；文件头注释申报用途、消费槽位与标定方法。

### 来源与体积

三类来源：手写程序化 SVG（平铺纹理首选）；Canvas 2D 程序生成 → 缓存为静态位图（开发期生成、产物入库，运行时零依赖）；真实素材衍生 / 致敬性复用（须灰度化或成对处理）。

体积预算：单张位图 ≤ 100KB；全部资产总预算 1.5MB。可平铺纹理一律无缝（`stitchTiles` / 周期性生成）。

## 六、预设 API 与合成规则

- **基础配置**：字符串预设 prop —— `material` / `lighting` / `decoration`（`tier` 已实现）。选择的是库内定义好的资产组合与档位。
- **高级配置**：数值调整参数 —— `textureIntensity` / `lightingIntensity` 等，实现为语义响应系数（`--au-texture-scale` / `--au-lighting-scale`）的 prop 化映射，只调整已定义资源的表现强度，不允许任意传入自定义材质、光源、主题。
- **合成优先级**：显式 prop 永远覆盖材质默认组合。
- **interactionEffect（点击特效）**：独立效果资源类别（`src/assets/effects/`），API 设计待特效立项。

## 七、性能实现原则

1. **滤镜进资产、不进运行时**：SVG 滤镜写在资产文件内部（解码时栅格化一次）；禁止对组件元素挂运行时 `filter: url(#…)` 或大面积动态滤镜。
2. **层叠上下文隔离**：使用混合模式的容器建立独立层叠上下文。
3. **库零运行时依赖**：组件运行时只有 CSS + 资产 + React peer deps；Canvas 生成在开发期完成；远期 WebGL 也应渲染为纹理喂给现有槽位体系。

## 八、渲染实验室（RenderLab）

Playground 内长期保留的美术资源研发与渲染验证工具，与 Materials 校准台的分工：

> **RenderLab 造资产、验渲染；Materials 校参数。**

实验台可调整参数，但不复制正式材质的绘制逻辑（可移植性以自动化断言验证，不靠复制规则）。八个区块的用途明细见 `docs/playground.md`。

## 十、验收与校准

1. **swatch 无干扰验收**：三种材质以约 420×300 无边框、无文字、无装饰的色块独立展示即可辨认身份。
2. **截图矩阵回归**：材质 × 主题 × 尺寸 × 强度参数矩阵留档对比。
3. **量化标定（适用边界）**：带滤镜的 SVG 不可用 `Image + drawImage` 测量（Chromium 丢弃滤镜 rect 返回空图）；有效路径为 CSS 渲染 + PNG 截图回读（"有/无纹理"成对截图 → 亮度差统计）。
4. **自动化通过 ≠ 视觉验收**：一切材质资产以肉眼可辨为准。
